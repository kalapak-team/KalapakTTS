# Third-party model attribution

## VoxCPM2 browser model

- Source: https://huggingface.co/Uddom/voxcpm2-khmer-webgpu
- Base: https://github.com/OpenBMB/VoxCPM
- License: Apache License 2.0
- Attribution files: `public/VoxCPM2-LICENSE.txt`, `public/VoxCPM2-NOTICE.txt`
- Public manifest: `public/model-manifest.json`

The 4-bit WebGPU model is a modified conversion of VoxCPM2. It is not claimed to be identical
to the original PyTorch model. The model card does not formally evaluate Khmer intelligibility,
and it has not been benchmarked for this RTX 4050 Laptop GPU in this repository.
